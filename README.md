# 🤖 JARVIS Android

دستیار صوتی فارسی JARVIS برای Android.

# 📱 دانلود JARVIS

[**⬇️ ورود به صفحه دانلود APK**](../../actions/workflows/build-apk.yml)

## 🟢 راهنمای خیلی ساده دانلود برای کاربران

**مرحله ۱:** روی دکمه **«⬇️ ورود به صفحه دانلود APK»** در بالا بزنید.

**مرحله ۲:** در صفحه بازشده، جدیدترین ردیفی که کنار آن علامت سبز ✅ دارد و نام آن **Build JARVIS APK** است را باز کنید.

**مرحله ۳:** صفحه را به پایین ببرید تا قسمت **Artifacts** را ببینید.

**مرحله ۴:** روی فایل **JARVIS-Android-debug** بزنید تا فایل دانلود شود.

**مرحله ۵:** فایل دانلودشده ZIP است. آن را Extract / استخراج کنید.

**مرحله ۶:** داخل پوشه استخراج‌شده روی **app-debug.apk** بزنید.

**مرحله ۷:** اگر گوشی پیام اجازه نصب نشان داد، گزینه **Allow from this source / اجازه از این منبع** را فعال کنید و سپس **Install / نصب** را بزنید.

> ℹ️ برای دانلود Artifact ممکن است GitHub از شما بخواهد ابتدا وارد حساب GitHub شوید.

## ⚠️ اگر گوشی اجازه نصب نداد
در تنظیمات Android، اجازه **Install unknown apps / نصب برنامه‌های ناشناس** را برای مرورگری که با آن APK را دانلود کرده‌اید فعال کنید و دوباره APK را باز کنید.

## ✨ امکانات JARVIS
- تشخیص گفتار فارسی (`fa-IR`)
- Wake word: «جارویس» / `Jarvis`
- پاسخ صوتی با Android Text-to-Speech
- رابط کاربری HUD تیره و آینده‌نگر
- ورودی متنی
- دکمه روشن/خاموش میکروفون
- ساخت خودکار APK با GitHub Actions

## ⚙️ سازگاری
Android 8.0 (API 26) و بالاتر. مناسب برای Samsung Galaxy A13 و دستگاه‌های سازگار.
